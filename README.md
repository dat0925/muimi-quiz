# 無意味クイズ大全 🎃

タイトルと絵文字で **答えが完全にバレている** のに、問題文だけは頑（かたく）なに百科事典調で無駄に難解 —— というジョークサイトです。全70問（うち**ひっかけ10問**）。

## これは何？

- カード上部に「◯◯クイズ」という**タイトル**（＝答えそのもの）
- 中央に特大の**絵文字**（＝これも答えそのもの）
- 下部に、やたら格調高い**百科事典調の問題文**（ふりがな付き）
- 「答えを見る」を押すと……もちろん、タイトルと同じ答えが出てくるだけ

真面目な見た目と、内容の無意味さのギャップを楽しむためのサイトです。

### ひっかけ問題（10問）

通常はタイトル＝答えですが、**「ひっかけ」の朱印バッジ**が付いた問題だけは別物。タイトルと絵文字は“わざとらしいおとり”で、問題文を正確に読むと答えが意外なものになります（例:「世界一高い山クイズ 🏔️」の答えは *エベレスト* ではなく **チンボラソ**）。ひっかけの答えはいずれも「意外だが事実として正しい」ものです。

## 機能

- 📱 モバイルファーストのカード型UI（1画面に1問）
- 👆 左右スワイプ / マウスドラッグ / 矢印ボタン / キーボード（←→）で前後移動
- 📊 進捗表示（例: 12 / 70）とプログレスバー
- 🔀 シャッフル（出題順のランダム化）
- 🈁 答え表示のトグル
- 🚩 ひっかけ問題には朱印風の「ひっかけ」バッジを表示
- 🎨 落ち着いた「紙の百科事典」風デザイン、明朝体ベースで日本語が読みやすい

## 技術

- 単一の `index.html` のみ（**Vanilla JS + CSS、外部ライブラリ・ビルド不要**）
- スワイプは Pointer Events でタッチ・マウス両対応
- クイズデータ（70問）は HTML 内に JS 配列として埋め込み

## ローカルで動かす

`index.html` をブラウザで開くだけです。

```
# 任意：簡易サーバで開く場合
python3 -m http.server 8000
# → http://localhost:8000
```
